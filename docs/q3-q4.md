# Q3: Uniform Cost Search

Uniform cost search (UCS) expands the frontier state with the smallest
accumulated path cost, `g(n)`. Unlike breadth-first search, which minimizes the
number of moves, UCS handles different step costs and returns a
minimum-cost path. The fringe stores each state's actions and accumulated cost,
so each successor cost is calculated as `cost + stepCost` without recomputing
the cost of the entire action list.

# Q4: A* Search

A* orders the fringe by `f(n) = g(n) + h(n)`, where `g(n)` is the accumulated
cost and `h(n)` estimates the remaining cost to a goal. With a consistent
heuristic, a state's lowest-cost path is settled when it is expanded, so
graph-search A* remains optimal. The heuristic guides the search toward the
goal and can reduce expansions while preserving the optimal path. With
`nullHeuristic`, A* uses only `g(n)` and behaves like UCS.

On `mediumMaze`, UCS finds a 68-move solution after expanding 269 nodes. A*
with Manhattan distance finds the same-length solution after expanding 221
nodes.
